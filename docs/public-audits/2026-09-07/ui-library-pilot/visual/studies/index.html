Library groundingDither Kit’s Bayer canvas texture motivates the landscape. This is a custom generated static SVG, not its chart or gradient implementation.
Explicit experimentSage and parchment tones extend the ember palette for this study. Large display typography and visible grain are intentional departures.
Runtime recommendationUse a static render for the hero. Adapt Dither BarChart for one usage view, with semantic values and render-on-demand. No canvas per task row.
Prototype interactions: suggestion buttons fill their own textarea. Preview send only displays a local message and preserves the draft. Other app chrome is illustrative. All compositions show a returning workspace with an empty task; a genuinely new install must show Mako’s provider/workspace setup steps.
