# Local Control agent issue ledger

Updated 2026-09-24. Tracks the supplied Cursor session feedback and the related
capture/API failures found while reproducing it. The [wayfinder](local-control-map.md)
owns delivery order; this file owns each complaint's disposition and closure check.
The [investigation](audits/2026-09-23/local-control-capture21/README.md) records the
source bundle's loss notices, repros, counterexamples and measurements. Missing
history and inferred causes are not treated as established facts.

**Status meanings:** “Fixed locally” means source and scoped regressions pass, not
that the running app has received them. “Partial” has specific work remaining.
“Open” needs implementation or evidence. “Cause corrected” rejects the reported
explanation but retains the user-facing failure and any diagnostic work.
All local fixes still pass through [installed acceptance](local-control-map.md#lc-23--preview-isolation-and-installed-browser-rollout).

## How to close an issue

Attach the reproducer, changed code/contract and independent outcome check. State
which target/build was tested and whether deployment happened. Preserve rejected
explanations and failed candidates. Link the original complaint to its check;
“better help”, “60 fps output” or a passing unit test alone does not close an
end-to-end usability or fidelity complaint. Reopen an entry if a real agent still
needs a workaround that its closure check says should be unnecessary.
